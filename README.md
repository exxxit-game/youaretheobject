# You are the object

«Лаборатория неизвестного / Точка зрения»: знакомый коридор становится опытом восприятия.
Через движение, наблюдение и выбор человек открывает мир и себя с другой стороны.
За дверями — научные опыты и философские вопросы; отдельная ветвь — добровольные
вымышленные сделки и комната последствий. История человеческого знания связывает
материалы, которые добавляются постепенно. Название сообщества — «Общество ноль».

Цели: компьютер, включая ноутбук с тачпадом; телефон; Quest 3 / WebXR.
Сейчас есть экранный прототип подъезда и прежняя лабораторная VR-комната.
Полный новый маршрут на телефоне и в Quest ещё не проверен и не выпущен.

План: [утверждённая основа](docs/research/perception-corridor.md),
[комнаты, этапы и устройства](docs/research/corridor-room-plan.md),
[текущее состояние](docs/state.md), [каталог материалов](docs/research/perception-knowledge.md).
Рабочая очередь читается командой `node tools/corridor-brief.mjs` из единой карты.

Существующий сайт: [youaretheobject.com](https://youaretheobject.com).
Ссылка не означает, что экспериментальная ветка уже опубликована.

---

A browser perception game: one familiar corridor, scientific experiences and philosophical
questions behind its doors, with a separate voluntary fictional-deal branch and money checkpoint.
Human knowledge is the long-term direction; rooms are developed and checked incrementally.
Targets: desktop including trackpad, mobile and Quest 3 / WebXR. The stairwell screen prototype
and legacy laboratory room exist; the full new mobile/immersive route is not yet validated or released.

For contributors: [AGENTS.md](AGENTS.md), [WORKFLOW.md](WORKFLOW.md),
[ARCHITECTURE.md](ARCHITECTURE.md). Current owner decisions take precedence over historical plans.
