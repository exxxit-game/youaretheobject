### Part 1. VRC.Quest.Performance.1 [read 2026-10-13 via `metavr docs fetch`]
- URL https://developers.meta.com/horizon/resources/vrc-quest-performance-1/ ; last_updated "2025-10-22".
- Criteria: "Apps must maintain a rendering rate of at least 60 fps"; refresh "72 Hz, 80 Hz, 90 Hz, 96 Hz, 100 Hz or 120 Hz".
- Steps to test: "1. Use the app for the length of the content or 45 minutes, whichever is shorter." "2. Launch the OVR Metrics tool and select the log file for your app." "3. Observe the FPS graph to determine if extended periods of rendering rate below 60 fps are present."

- Exception relevant to measuring: "Due to the additional GPU cost incurred when streaming a play session or recording it to video, applications are allowed to run at a slightly lower rendering rate _while streaming or recording to video_." -> screen capture during the run costs GPU (our screencap/quest-look frame must stay out of measured windows).

- CPU and GPU levels, https://developers.meta.com/horizon/essentials/cpu-gpu-levels, last_updated "2026-09-11" [read]: "The operating system keeps your CPU and GPU levels at the lowest value within a range that preserves your application's framerate."; Quest 3 SustainedHigh CPU "4 to 4", GPU "3 to 5"; Boost CPU "4 to 6 (Quest 3/3S)"; "GPU level 5 requires dynamic resolution."; profile with "OVR Metrics Tool — Real-time overlay showing CPU and GPU levels", "Meta Quest Developer Hub — Performance Analyzer view", "Logcat stats — Logs for tracking level changes".
