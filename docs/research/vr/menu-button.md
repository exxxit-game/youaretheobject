## Every button, as players know it

- Grip (side): holding interactables, default grab; the page notes some apps use it otherwise; VRC.Quest.Input.2 (Recommended) says grip, not trigger, for picking up | "Simulate gripping actions, such as holding onto interactables." ; table: "Grab" | https://developers.meta.com/horizon/design/controllers/ ; https://developers.meta.com/horizon/resources/vrc-quest-input-2/ | 2026-09-25 ; 2024-07-31 | 2026-10-13
