## Fit for Object (reviewer's judgment, not facts)
- Participant time: one round is 5 min study + 2 min delay + up to 5 min recall, about 12 min; the paper's two-round comparison takes about 45 min.
- Task/tension: a clear memory challenge (21 faces), but it needs famous faces known to the player, which is culture-bound.
- Within-person reveal: weak in Object — the paper's comparison is HMD vs desktop; a Quest-only player can see their own score but not the immersion effect. A "virtual monitor inside VR" control would be a different experiment.
- Works if the player expects tricks: yes, there is no trick; but the effect itself is the question.
- Space tier: seated (look around from one spot, rotation only).
- VR or mixed reality: VR; the palace replaces the room. Mixed reality would be a new condition (faces placed around the player's own room, a real "memory palace") and is untested.
- Quest 3 feasibility: easy (a 360° scene, 21 pictures, numbered markers); recall was spoken to an experimenter, so automatic scoring needs a pick-from-list answer or speech recognition, which changes the measure from free recall to recognition.
- Replication: none found for the HMD advantage; the paper's own first-round comparison was null and the effect came from the crossover order. The method of loci itself is robust (classic literature, not this paper); VR versions on desktop (Legge et al. 2012, Acta Psychologica) found VR palaces equal to imagined ones — full text not obtained.
- Ethics: none special.
- Verdict: reject as a room — the headline HMD advantage is not supported on first exposure, has no independent replication, and needs a desktop arm a home player cannot do within the headset; keep as background for any memory-palace design.
